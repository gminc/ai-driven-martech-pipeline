# 顧客長期價值預測（Day 12）

只用顧客第一次下單當下就知道的資訊（買什麼、買幾件、花多少、從哪個來源與媒介來），用 BigQuery ML 線性迴歸預測他接下來 30 天還會帶來多少回購營收，再把預測值依通路與活動加總、除以取得成本，最後和 Day 05 合成器藏的四種顧客類型對照。

- 預測目標：首購後 30 天內的回購營收（不含首單），單位新台幣
- 訓練與驗證只用首購後已滿 30 天的 1,458 人（資料最後一天 9/16），依首購日期切：8/08 以前 1,183 人訓練、8/09–8/17 的 275 人驗證，同一天不拆開、不隨機切
- 首購在 8/18 之後的 1,003 人只做預測，和驗證集一起寫進 `martech_dw.mart_customer_ltv`
- 不用 Day 11 的分群當特徵：分群用了訂單數、回購間隔等回購紀錄，拿來預測未來回購等於偷看答案
- 答案表放在獨立資料集 `martech_gt`，只有 `reveal.sql`、`check.sql` 會讀

## 執行

```bash
bash ltv/run.sh              # 在儲存庫根目錄執行，印出預估費用後輸入 yes 才建模型
bash ltv/run.sh --unseen     # 另外建「活動代號也當特徵」的對照模型，示範沒看過的類別
AUTO_YES=1 bash ltv/run.sh   # 跳過確認
```

需要先完成 Day 07（`martech_dw.fct_orders`、`fct_ad_daily`），答案表不存在時 `run.sh` 會呼叫 `scripts/load_ground_truth.sh` 載入。

| 檔案 | 內容 | 讀答案表 | 費用 |
| --- | --- | --- | --- |
| `features.sql` | 建立 `ltv_features`，一位顧客一列：首購商品、件數、金額、來源、媒介、活動，30 天回購營收，`label_complete`、`is_eval` | 否 | 免費額度內 |
| `model.sql` | 正式模型 `ltv_linreg`：線性迴歸，`is_eval` 當 CUSTOM 切分欄位，不放活動代號 | 否 | 約 NT$ 0.1 |
| `evaluate.sql` | `ML.EVALUATE`：驗證集的 MAE、RMSE、中位數絕對誤差、R² | 否 | 免費額度內 |
| `baseline.sql` | 驗證集上三種方法比誤差：全體平均、依首購商品平均、線性迴歸 | 否 | 免費額度內 |
| `predict.sql` | `ML.PREDICT` 預測驗證集與新顧客，負數截成 0，寫進 `mart_customer_ltv` | 否 | 免費額度內 |
| `value.sql` | 8/18–9/16 新顧客依通路 × 活動：取得成本、首單金額、預測回購、價值 ÷ 成本 | 否 | 免費額度內 |
| `reveal.sql` | 預測值 × 答案表：依真實類型、依首購商品 × 真實類型 | 是 | 免費額度內 |
| `model_campaign.sql` | 對照模型 `ltv_linreg_campaign`，多放活動代號 | 否 | 約 NT$ 0.1 |
| `unseen.sql` | 同一批新顧客，兩個模型的預測並排 | 否 | 免費額度內 |
| `check.sql` | 9 項 OK／DIFF：列數、依時間切分、預測無空值與負數、線性迴歸贏過全體平均、高頻買襪客的預測是其他類型的 1.5 倍以上 | 是 | 免費額度內 |
| `run.sh` | features →（確認）→ model → evaluate → baseline → predict → check＋答案表隔離檢查 → value → reveal →（unseen） | | |

## 9/26 實測

| 方法（驗證集 275 人） | MAE | RMSE | 平均預測 | 平均實際 |
| --- | --- | --- | --- | --- |
| 全體平均 | 131.0 | 171.8 | 96.4 | 77.4 |
| 依首購商品平均 | 111.4 | 161.8 | 104.8 | 77.4 |
| 線性迴歸 | 110.9 | 160.8 | 102.4 | 77.4 |

- `ML.EVALUATE`：MAE 110.9、RMSE 160.8、中位數絕對誤差 82.4、R² 0.113
- 線性迴歸只比「依首購商品平均」好 0.5 元，來源與媒介幾乎沒有加分
- 揭曉（驗證集）：高頻買襪客平均預測 169.9、實際 244.8；沉睡客預測 103.4、實際 0；首購 `sock-crew-daily` 的高頻買襪客與沉睡客預測是 178.5 與 173.6，首購時分不開
- 價值 ÷ 成本：google_cpc 三個活動 2.27–2.56 最高，meta 的 training-socks 0.42 最低；首購訂單的 utm 等於最後接觸，google 搜尋會被高估（Day 08）
- 沒看過的活動：`ltv_linreg_campaign` 對 autumn-cotton 的新顧客預測 746–927，不放活動代號的正式模型是 -12–174
- `CREATE MODEL` 實際處理約 0.15 MB，照最低 10 MB 計費，每個模型約新台幣 0.1 元，17–19 秒
